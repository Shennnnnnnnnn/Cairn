## 协议、审阅与成本边界

四个执行者均结束、逐份完整公开报告审阅冻结后，才由宿主运行隐藏标签评分。数值检查只验证契约及原始 CSV 重算，不读取标签，也不判定因果、采集语义或全部自然语言数字。人工审阅知道此前参考答案，不能称为盲评；逐份内容与边界见 qualitative-audit.json。

本轮统一使用 v2 契约，明确同一规范化 `(file, entity, metric)` 不能以不同窗口/运算重复充当两条检查。验收算法与旧契约/旧分数不改；与历史 Pi 的契约文字差异单列。

Codex 的 input_tokens 包含缓存输入；表中 total=input+output，未缓存输入=input−cached_input，reasoning_output 不重复累加。Pi 沿用原始 input/cacheRead/cacheWrite/output 及 totalTokens。订阅 CLI 的记录用量不是账单，本轮不估算美元金额。CLI 输出事件和配置方式可参见 [官方非交互说明](https://developers.openai.com/codex/noninteractive) 与 [配置参考](https://developers.openai.com/codex/config-reference)。

正式四次总记录 3,523,283 tokens。首批 round7 的三个 MCP 未收到数据库/验收配置，任务误写仓库默认数据库且无运行中宿主验证器，整批作废，四次共 3,372,021 tokens 单列。作废是可复核的接入错误，不能当作模型失败或择优删除样本；标签、独立事后复算、日志、误路由任务与作废原因均保留。原两个合成探针另耗156,339 tokens，未验证 Git 内数据库隔离或宿主验收，仓库内纠正探针另耗86,047 tokens，合计排除的模型调用用量为3,614,407 tokens；测试及探针明细见 auxiliary-probes-and-tests.json。所有正式臂重新运行，没有预算切断；CLI 原生错误重试和模型服务限制保留。

原生与 Cairn 均禁用用户全局 MCP/插件/记忆/skills、网页搜索和子代理，任务指令禁止联网；Cairn 仅启用本轮安装的冻结本地 hooks。每个进程使用私有凭据副本和独立临时目录，结束删除私有配置；全局 Codex/Pi 配置哈希不变。workspace-write 限制写入，不证明读隔离。独立检查全部81条公开命令/MCP记录、19个文件变更事件及100个原生嵌套工具调用，未观察到显式越界或临时目录偏离；见同目录 scope-review.*.json。脚本内部和全部OS行为不在此范围，不能把路径检查当作隔离证明。

冻结与记录审计 **852/852** 通过；它是协议完整性检查数，不是内容正确性分数。
