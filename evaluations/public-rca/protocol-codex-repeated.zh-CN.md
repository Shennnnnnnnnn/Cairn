# 新难题重复对照：启动前协议

模型 `gpt-6.1-sol`，Codex `model_reasoning_effort=xhigh`。比较原生 Codex 与第七轮当前 Cairn。3道新题，每题每配置3次，共18个全新原生会话，最多3个同时执行。不设置评测执行时长、token或工具次数上限。模型服务、上下文、原生重试及宿主只读验收子进程的安全超时保留；没有强制中断或强制恢复。

## 选题与冻结

历史真实执行 manifest 只涉及 case-01 至 case-04。排除这些窗口及含第二个已知故障时刻的窗口。剩余29个事件按时间顺序分三个时间段，每段选一道，三个资源类别各不相同且窗口不重叠。目标对象不用于选择或过滤输入，资源大类标签仅用于类别覆盖分层。

难度代理只计算原始指标的多对象同时变化：每条源时序前后各至少2点，相对均值差至少25%，且均值差相对双侧标准差与1%量纲稳定项至少1；至少2条时序变化才计一个多信号对象。最大化三个窗口的 `多信号对象数*100 + 信号所在层数*10 + 变化时序数/1000` 之和，平分取较早时间元组。候选和分数在任何模型执行前保存。该代理不是验证过的比赛难度评级，原值变化也不自动具有累计计数器的物理意义。

不加类别约束的初稿选出了三个 I/O 事件；它在任何模型调用前归档为 selection-only-v1，模型调用及成本均为零。最终分层约束在正式启动前冻结，不读输出后换题。

保留全部57个CSV在时刻前后各600秒内的原始行与全部对象，只有时间过滤，不按已知对象/类别筛选列、文件或行。各题 TASK 沿用历史中性模板，统一追加契约v2。每题六个执行者输入完全相同。Cairn额外加载自身同一份skill和五工具指导，原生保留普通分析脚本与输出文件能力。当前src/dist/skills和此前已验证的第七轮85个文件完全一致，冻结后不优化框架。

按重复轮次轮转案例顺序、交替原生/Cairn先后；固定队列和最多三个并发，空位继续派发。不依据失败重跑或挑选最好一次。每次独立工作区、原生线程、DB、临时目录与私有配置。网页搜索、用户全局MCP/插件/skills/记忆、子代理关闭；指令禁止联网、读取其他工作区和标签。workspace-write不证明读隔离，另外审查公开工具和文件路径。

Git仓库内的合成marker探针确认MCP私有DB、原生owner、显式CAIRN env_vars及宿主验收生效后，才封存协议并启动。探针无领域数据或标签，其用量单列。每个成功start回执还须在该次独立DB找到同一原生线程与宿主验收/必需文件，否则是实验基础设施故障。没有start、多个任务、挂起、模型服务失败均如实计行为/完成失败，不因此另跑一次。

## 成功与成本

- 正确率：首选对象、资源类别和node/pod/service层级同时命中的次数/全部9次。缺失或不合法答案记未命中。服务级对象只允许 `-grpc/-http` 后缀与无后缀等价；pod不能自动升级为service/node。旧raw对象＋类别分数另存，不改历史评分。
- 完成率：自然结束、有answer/REPORT/checks三文件且候选字段有效；Cairn还须恰好一个真实owner任务、状态completed、当前报告有效和当前宿主verification通过。两宿主的状态判据差异明确列出。独立数值验收另列，不把它当根因正确性。
- 错误完成：完成但首选对象/类别/层级未命中；同时报告错误完成/全部次数及错误完成/完成次数。正确但数值验收失败不算有效交付。
- 有效交付：完成、独立原始CSV数值复算和联合标签全部通过。标签不用于运行中的验收；模型也不能自报独立正确。
- 成本：记录用量=input_tokens+output_tokens；cached_input已包含在input，reasoning_output不重复累加。未缓存输入另列。失败或缺usage为下界/未知，不记成免费；每次有效交付成本=包括所有失败的全部记录tokens/有效交付数，零有效交付时不可定义。不估算订阅美元金额。

18个执行者全部结束，逐份完整公开报告审阅冻结之后，才统一隐藏标签评分；无报告须明确记缺失。用冻结引擎和内存Store复查Cairn报告/proof，不调用模型或修改源数据库。逐次保存原始模型/等级元数据、公开命令/MCP记录、文件变更元数据、独立验收与失败，不展示或分析私有推理内容。

## 稳定性解释

每题分别报告3次结果是否一致、时间/tokens的中位数、最小/最大值、标准差与CV；CV>0.25或max/min>2标记为观察到成本波动。汇总9次并报告三题宏平均、每题范围、9个对应(case,repeat)的胜/负/平，不将9次当成9道独立题。

全部3次相同只称“本次重复内一致”，不推断长期稳定。比例的Wilson区间可作为假定独立采样时的描述性参考，但同题、同一天测试床、同网关与缓存相关会削弱该假设，不用于宣称统计显著。只有3个独立事件、难度代理未经验证、公开答案潜在训练污染和模型后端路由未经独立证明，均须保留。没有自然中断就将恢复记N/A，工程重载检查不冒充模型恢复率。
