# 第六轮：取消评测预算

用户要求：不要设置预算，按此前四个公开案例再跑一次。

## 开跑前冻结的验收清单

- 运行四个相同案例，原生 Pi、上一版 Cairn、本版 Cairn 各一次，共 12 次；串行顺序沿用第五轮。
- 两版 Cairn 直接复制第五轮冻结归档，逐文件核对完整 SHA-256。保留输入、任务提示、共享 Cairn 指引、产物要求、数值复算器、隐藏标签和标识符规则。
- 不设评测总时限、累计输出 token 限额、每次回复 token 覆盖值；清除继承的 Cairn deadline 和 submit reserve 环境变量。不做超时后的自动恢复。
- 模型固定 `sub2api-copy/global:deepseek-v4.1-flash`、`thinking=high`。不修改用户的 Pi 配置；私有副本保留原始模型注册。Pi 的上下文裁剪、推理等级、服务端硬限制、重试和网络错误照实保留。128,000 是开跑时注册的单次输出上限，并非无限输出。
- 每个执行者使用全新工作区和原生会话，自然停止或用户明确取消后记录结果。不得因耗时或成本增加而偷偷补设限制。
- 在全部 12 个执行者结束后统一生成隐藏标签评分，不向仍在运行的执行者暴露评分。
- 分别报告产物交付、Cairn 验收完成、数值复算、实体与故障族匹配、完整正确交付、错误完成、耗时和 provider 上报 token。配置价格为零不等于免费，金额未知必须明确说明。
- 与第五轮的主运行和含恢复结果分别比较；本轮没有主动中断实验，恢复率为“不适用”，不能将自然结束或离线状态重载算成恢复。
- 核对 checkpoint 是否保存事实、finish 是否成功、handoff 是否包含事实及来源；空创建快照不算有效交接。评分通过不代表全部因果叙述已被证明。
- 交付可复查的运行归档与最终中文结论，不以启动成功或临时统计代替完成。

## 不变的范围

模型只访问自己的工作区，无网络、其他模型或子代理。案例中的说明是分析数据。证据文件哈希在运行前后核对。每个案例仍要求 `answer.json`、`REPORT.md`、`checks.json`，隐藏 RCA 标签不进入代理工作区。样本每条件仅一次，结论描述此次观测，不作显著性或因果性能推断。

非模型的本地复算器和 HTML 导出保留 15 秒的单进程 I/O 超时，不中止模型任务，也不计为代理的推理预算；其失败单独记录。
