# 第九轮：同模型 Pi 原生 / Cairn 重复对照预登记

用户已明确选择两组均使用 Pi / global:deepseek-v4.1-flash，固定 provider=sub2api-copy、thinking=high（沿用此前 Pi 设置，模型声明支持 reasoning）。相同三题各三次、两组共18个全新会话；固定轮转交错、最多3并发，无评测时长/token/调用次数预算，无自动中断或选择性重跑。保留原生上下文、服务限制及宿主验收器安全超时。合成接入探针单列。

输入、TASK、原生提示、Cairn启用提示、v2产物契约、复算器和标签政策与 round8 字节相同；同题开发集复测，非新留出题。运行前冻结 src/dist/skills、runner/driver、输入和评分文件；正式开始后不修改。处理变量为四类 checkpoint 对象数组的单层编码兼容、Pi 校验前参数准备及通用的同对象机制比较/因果方向指导。五工具、原目标、证据、原生执行和轻量增量黑板保留；不加入领域指标、案例名、答案或机制/层级优先级。

每次独立工作区、DB、session、临时目录和私有 Pi 配置。关闭全局扩展、skills、MCP及上下文文件，只加载冻结 Cairn 扩展和skill；配置不设模型 maxTokens 覆盖。Pi 原生工具没有 OS 级沙箱，因此这是目录/会话隔离加指令约束，不声称完全访问隔离。全局配置哈希核对，凭据副本在每次结束后删除且不归档。真实探针先核对模型/effort、原生 owner、私有DB、验收器身份和当前完成证明。只读取公开工具、报告及用量/路由元数据，不读取私有推理。

所有18次结束、完整最终公开报告阅读并哈希封存后，才统一进行隐藏标签评分。top1对象+资源族+精确层级联合正确；仅service真值允许-grpc/-http后缀等价，不跨层升级。数值、格式与结论正确性分开计量。

完成=自然结束、三个文件非空、候选字段有效；Cairn额外要求唯一真实owner任务completed、报告有效和当前验收proof。有效交付还要求联合正确、产物契约/复算通过与输入完整。错误完成=完成但标签错；无效完成=完成但未有效交付。全部失败和所有尝试成本计入。

Pi usage 的 input、output、cacheRead、cacheWrite 分项记录并求总量，原始 totalTokens 留作核对；不能重复加 reasoning。没有实际价格时配置cost=0/缺失表示账单未知，不等于免费。报告全尝试tokens、非缓存输入/输出、缓存、耗时及每次有效交付成本。round8 Codex结果只能作跨模型历史参考，不能把变化归因于本轮框架。每题3次的median/range/CV及一致性单列；CV>0.25或max/min>2标记样本波动，3个事件不能证明长期稳定。未发生真实中断/恢复时恢复N/A。
