# 四模型 × 三种执行配置：单道难例，无评测预算

## 开跑前验收清单

- 选定既有 `case-03`，在四个指定模型上各跑原生 Pi、上一版 Cairn、本版 Cairn，共 12 个全新会话。上一版指冻结的 Cairn 版本，不等同于原项目 Cairn-main。
- 选题依据在本轮推理前确定：上一轮三个配置均定位到相同对象，但原生 Pi 的首选故障族与两个 Cairn 版本分歧。混合资源信号适合检验替代解释和时间顺序。历史结果仅用于选题，不混入本轮成绩。
- 模型固定为 `global:deepseek-v4.1-flash`、`cn:step-5-preview`、`cn:glm-5.3`、`cn:kimi-k3-1`，均使用当前已配置接入端 `sub2api-copy`。清单接口已确认四个 ID 可用；不能独立验证网关内部实际路由。
- DeepSeek、Step、GLM 使用 `thinking=high`。Kimi 沿用用户注册的 `reasoning=false`，请求 `thinking=off`。这是当前接入配置下的可用效果比较，不是统一推理开关的模型能力比较。
- DeepSeek、Step、Kimi 的注册保留原样。GLM 仅在临时私有配置中注册别名；上下文 1,000,000、输出 131,072、推理及等级映射取自本机 Pi 1.1.0 自带 `zai/glm-5.3` 目录。接入端只返回 ID，因此这些是客户端登记值，不是接入端承诺。Kimi 登记输出 1,049,000 高于登记上下文，保留现状并检查是否出现实际限制。
- 不设评测总时限、累计输出限额、单次回复覆盖值、Cairn deadline 或 submit reserve；不主动中断，不自动开启新会话补跑。保留 Pi 与服务端原生限制、裁剪和重试。失败按原结果计入，不选择性替换正式样本。
- 两版 Cairn 直接复制上一轮完整冻结归档并逐文件校验。输入证据、共同任务、Cairn 指引、三项产物、数值复算器和隐藏评分器保持不变。原版 Pi 使用相同原生工具。
- 所有配置共同增加临时文件约束：写在各自 `cwd/.tmp`，并设置独立 TMPDIR/TMP/TEMP。除此之外共同提示沿用上一轮。该变动意味着本轮与历史数字不构成严格重复对照。没有操作系统沙箱，不宣称硬隔离。
- 12 次串行运行，按模型成组并轮换三个配置的次序。记录接入端缓存和耗时；顺序、缓存冷热及服务负载可能影响成本和时间。每个单元仅一次，不推导统计显著性或通用排行榜。
- 全部执行者结束后才生成隐藏标签评分。会话只看自己的案例和产物，不提供历史回答、标签或评分反馈；不联网、不访问其他案例、不调用模型或子代理。证据文件前后核对哈希。
- 分开报告：进程自然结束、产物交付、数值复算、Cairn 验收、实体命中、故障族命中、正确交付、错误完成。正确交付要求正常结束、产物/数值复算通过、框架完成（适用时）和实体＋故障族均正确；错误完成指已通过对应执行配置的完成条件但标签结论错误。
- 报告每单元耗时、输入、输出、缓存 token、请求错误和原生重试。错误可能漏记用量时标为下界；不同分词器和缓存语义不能直接换算费用。配置零价格不代表免费，实际金额未知。
- 检查 checkpoint 的增量主张、finish 调用、handoff 的来源和已保存内容。状态可读不等于实际中断恢复；本轮不主动中断，恢复率不适用。独立审阅最终报告的指标口径、观测与因果解释，不把复算通过或标签命中等同于全文正确。
- 交付完整 12 单元矩阵、可复核运行归档、中文结论及必要 UI 入口。不修改核心框架，不以探针或启动成功代替最终结果。

## 探针与宿主操作

开跑前工具协议探针只处理给定的 `marker=alpha`，不含排障案例或标签，与正式成绩分开。探针保留原模型登记且不设置 watchdog。发现宿主接入错误时先修探针，保留失败记录及其用量，不归因于模型。

正式运行的本地复算器、离线评分器和 HTML 导出保留 15 秒的进程 I/O 超时，不中止执行者，不作为模型预算。全局 Pi 配置不改动，凭据仅存在于仓库外的私有临时目录，完成后删除。

## 正式开跑前作废的宿主校准

最初运行目录含故障族单词，会通过工作目录泄露类别。发现后停止整轮：一个执行者自然结束，另一个被宿主终止，均不计正式成绩且不复用答案。没有生成隐藏评分。其原始日志、消耗和中断状态保留在 `2026-10-17-model-matrix-memory-unbudgeted/exclusion.json`。正式整轮改用中性目录，增加目录名检查，全部 12 个会话重新开始。额外校准成本另列，不因设置修正而隐藏。

## 运行中按用户要求改为模型间并行

用户随后要求“并行几个执行”。变更时前五单元已结束，Step 原生 Pi 正在执行；保留这些会话，另开 GLM、Kimi 两路，各自三个配置依旧串行，最多三个执行者同时运行。所有新工作区使用中性目录，模型配置、任务、冻结实现、工具协议和无预算约定不变。原串行宿主在 Step 自然结束并保存结果后，借助下一未启动目录上的宿主阻挡文件退出，防止重复启动 GLM/Kimi；此预期宿主退出不计为模型失败，不中断 Step。各路独立保存产物，通过清单中的绝对路径合并，工作区不搬迁。

变更在新两路启动前冻结于正式目录的 `parallel-amendment.json`。各路仅写执行结束标记，不自行生成隐藏标签成绩；全局宿主确认 12 个执行者结束、快照和输入一致后才统一评分。最终记录实际并发区间、各路运行器哈希与原始目录。前五次串行、后续部分并行且共享网关，耗时存在并发、时段和缓存混杂，不解释成严格速度排名。
