## 最终判断

本轮实现补上了探索黑板反馈、简短完成入口和独立结论审查，但**整体交付效率回退，不能认定优于上一版**。Cairn 联合命中从 2/4 到 3/4，同轮 Pi 也是 3/4；四例各一次，不能把多命中的一例归因于某个功能。Cairn 主阶段完成从 4/4 降到 2/4，“完成＋复算通过＋联合命中”从 2/4 降到 1/4；同轮 Pi 为 2/4。

错误完成从 2/4 到 1/4，但已完成任务中的错误比例仍是 1/2＝50%，与上一轮 2/4＝50% 相同。两个联合命中的任务没有完成，因此错误完成绝对数下降不代表完成质量已经提高。

主阶段 Cairn 耗时 2640.81 秒，比上一轮观察值多 59.3%；已记录 tokens 至少 2765106，比上一轮完整记录多至少 20.5%。同轮 Pi 为 2033.91 秒、至少 1523884 tokens。保留这次组合改动的失败结果，比依据单个命中例宣称优化成功更准确。

## 黑板改善到了哪里

四例都调用了 checkpoint，共七次；其中五次只有摘要，只有内存、网络两例真正提交结构化 Finding。两例探索 checkpoint 共保存七条前提边，最终图为十一条；新增的四条来自网络例成功的短 finish。上一轮没有中途 checkpoint，本轮已有两例可追踪的观测／假设分离，但不能称为稳定的多轮探索闭环。

内存例保留了“历史 max 触限而稳态 usage 较低”的矛盾，网络例也保存了不同层级候选。问题在于，单个 supported Finding 仍可能混入未经证实的因果解释；结构化引用验证只能确认前提存在且有依据，无法证明其含义正确。网络例就是有结构、有前提、有验收，首选层级仍错误。

与原版相比，当前没有独立 reason 调度步骤，也不会强制给每个未完成目标建立开放 intent。短黑板议程与去重提醒由同一原生会话消费；它们降低了常驻调度成本，也允许模型忽略结构化写入。原版 complete 本身同样没有独立语义 oracle，不能把原版完成标记当作正确性证明。

## finish、恢复与交接

主阶段被拒绝的 finish 从上一轮 16 次降到 8 次，但两个长调用仍截断并触发输出预算停止。内存例混入未决假设，网络例先混用两套输入、再引用 proposed 假设；只有网络例最后成功采用基于已存事实的短 finish。接口能力已生效，真实使用负担仍未解决。

两次自然输出预算停止均启动固定 180 秒新会话恢复：I/O 例超时且仍未通过复算；CPU 例在 171.80 秒完成续接，答案、报告和 checks 与主阶段字节一致。这是恢复交付；两例主阶段的首选都已命中，本轮没有纠正原本错误诊断的恢复样本。两次恢复共 351.82 秒、至少 283552 tokens；计入恢复后 Cairn 总用量至少 3048658 tokens，合计正确且验收交付为 2/4。本轮 Pi 没有自然恢复样本。

本轮四个 Cairn 主阶段均未登记 handoff，上一轮有五条。四份真实数据库副本的目标、约束、owner epoch 接管、旧验收失效、有界 context、文件和原库保留检查均通过；包含交接记录和报告／原会话定位要求的完整检查为 **0/4**。没有 handoff focus，不能把条件式 focus 检查的 true 当作实际焦点恢复证据。详见 [原始重载结果](runs/2026-10-17-aiops2022-round4b/handoff-restoration.json)。这也说明提示与字段变多后，已有交接行为没有自动保持。

## 下一轮应收敛的三件事

1. **收窄模型看到的完成契约。** 把事实更新放回 checkpoint，让正常 finish 消费已存覆盖和必需文件；完整旧输入的兼容留在宿主适配层。短任务仍保留有依据的直达方式。优先消除互斥写法混用和大段事实重复提交，不能靠放宽验收掩盖提交问题。
2. **让增量事实与未决方向更容易保存。** 摘要保存与 Finding 更新显式区分，以小型事实／假设／下一检验作为主要路径；保留反证和层级不确定性。避免增加更长的通用提示或无条件启动额外模型。独立语义审查继续由可选宿主／人工提供，并明确范围。
3. **恢复可追踪的交接，再做可选会话派发。** 明确保存知识、启动会话、接收方确认和责任接管的不同状态；借鉴 OpenRig 的候选版本绑定、epoch 隔离、幂等 request ID 和 unknown 回执。先让当前 handoff 可靠产出，不搬回 daemon pool／容器／跨机 registry；本轮没有实现或验证新的多 worker 执行。

## UI 与隔离复核

复盘 UI 分别展示任务状态、文件／契约验收和限定范围的独立结论审查。网络例会呈现“任务完成＋验收通过＋结论审查未通过”，防止把运行状态当作根因正确。离线评分只在全部模型结束后追加到十八个任务的 UI 副本，原始运行库未修改；详情见 [UI 入口](../../docs/public-rca-ui.zh-CN.md)。

主阶段显式文件路径检查 56 项、bash 命令 131 条，未出现自动可疑项；两段恢复另检查八个文件参数和十一条 bash 命令，完整阅读后未观察到隐藏评分读取。它们仍是有界路径／文本审查，不能证明不存在动态路径构造，也不能替代 OS 沙盒。
