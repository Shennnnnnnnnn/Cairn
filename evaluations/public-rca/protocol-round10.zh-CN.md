# 第十轮：事实复用与报告语义的同模型重复对照预登记

两组均使用 Pi 1.1.0 / provider=sub2api-copy / global:deepseek-v4.1-flash / thinking=high。沿用 round9 的同三题，各三次、两组共18个全新会话，固定轮转交错、最多3并发。无评测时间/token/调用次数预算，不自动中断、不选择性重跑；保留模型上下文、服务限制和宿主验收器安全超时。失败及其全部可观测成本保留，合成接入探针单列。

输入、TASK、原生提示、Cairn启用提示、v2产物契约、复算器、评分器与标签政策均保持 round9 字节不变。正式运行前冻结 src/dist/skills、运行器、协议和评分；运行期间不得改变。处理变量为定向事实读取的版本/依赖/引用状态、按最新修订的探索议程，以及复用可重算事实和保留时间/单位/缺测语义的通用指导。无需新增模型侧字段、工具、审查worker、领域解析器或预算，不包含案例、指标或答案硬编码。保持原目标—事实—提示—有区分力的下一步—增量保存/交接的原版思想。

每次独立 cwd、DB、原生 session、临时目录和私有 Pi 配置；关闭全局扩展、skills、MCP及上下文文件，仅 Cairn 组加载冻结扩展/skill。不覆盖模型 maxTokens。Pi 无 OS 沙箱：目录/配置隔离加指令约束不等于访问隔离。公开工具路径检查及已知例外需如实记录，不能宣称证明未访问其他内容。凭据副本退出时删除、不归档；全局配置核对SHA。只读公开工具/最终报告及用量、模型、effort元数据，不阅读私有推理。

完成判定：exitCode=0 且最后 assistant stopReason=stop，三个文件非空、答案字段有效；Cairn 额外要求唯一真实 owner、私有DB/验收器身份正确、任务 completed、报告门禁通过及当前版本的验收证明。历史已恢复的 provider error 不使自然完成作废，原始 turnFailed 保留。top1正确须对象+资源族+精确层级联合正确，仅服务级 -grpc/-http 别名等价。有效交付还需联合正确、契约/数值复算通过、输入未改。错误完成=完成但标签错；无效完成=完成但未有效交付。数值例子通过不代表整个自由报告正确。

所有18次结束并逐份完整阅读、SHA封存最终公开报告后才统一隐藏评分。不更改评分器或因报告质量改变标签分数。两组报告统一额外审查以下三维（每份可多项）：

- 时序：是否存在与原始记录不符的时刻、先后关系、窗口/采样/收集语义；分辨率不足仍断言因果时序也计入。保留恰当的不确定性不算错误。
- 单位：是否未提供依据却断言单位、速率、转换或分母；明确条件性解释/原始单位未知不算错误。
- 缺测：是否把未采集/无数据当0或正常、超出可用对照范围泛化；明确可用/未知边界不算错误。

每维记录 confirmed_issue / no_confirmed_issue / unavailable，列出具体报告语句与原始证据。no_confirmed_issue 只代表本次审查未确认问题，不是全报告正确证明；无报告为 unavailable，绝不记为质量通过。沿用 round9 已封存报告可用同一标准作历史对照，独立标明回顾性审查。附带数量/范围或因果过强的其他问题单列。人工审查已知公共案例，不是盲测。

成本保留 Pi input/output/cacheRead/cacheWrite，output含reasoning不可重复计算。全部尝试成本/有效交付；有服务错误时为记录下界；cost=0/缺失为实际账单未知。逐题给 tokens、非缓存输入+输出和耗时 median/min/max/CV；CV>0.25或max/min>2标记波动。比较本轮两组及历史 round9 同模型 Cairn 的趋势；历史样本、服务噪声和相同开发集不支持严格归因。三题相关重复样本不能证明长期稳定。无真实中断/接管则恢复N/A，自动连接重试单列。
