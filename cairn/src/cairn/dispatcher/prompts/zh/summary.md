# 任务
将下面的 {kind} 描述压缩成图节点/边上可读的短标题。

# 输出要求
只返回合法 JSON，不要输出其他内容：
```json
{"accepted": true, "data": {"title": "..."}}
```

# 规则
- 必须自行做语义压缩，提炼“主语 + 动作/结论”的中文短标题。
- 标题要承载实际内容，读起来像完整标题，例如“摘要拒绝原文截断”。
- 禁止直接截取原文前缀，禁止把描述开头裁成 20 字返回。
- 不要返回语义残缺的半句话、未完成短语或冗长原文。
- 硬性上限：标题必须不超过 20 个字符。
- 中文按字符计算，每个汉字算 1 个字符。
- 如果初稿超过 20 个字符，必须先改短再返回 JSON。
- 不要使用句号、解释、前后缀或 Markdown。

# 对象
id: {id}

# 描述
{description}
